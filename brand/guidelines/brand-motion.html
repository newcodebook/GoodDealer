动效规范

全部由 tokens/motion.css 驱动——时长/缓动 token + 命名 keyframes + 绑定类。语言从 Coin Seal 长出：颁章 · 骑缝 · 圜纹 · 贵金属光泽。下面每个正在循环。两级铁律：品牌时刻可表现，系统 UI 守克制；prefers-reduced-motion 关闭品牌层。

◆ 品牌时刻 · 可表现

开屏 / logo reveal / 成交 / 绑定 / 解锁 / 交权。beat 360–700ms · 一次性 · 贵金属。允许光泽、旋铸、涟漪；仍无弹簧、无橡皮筋、内方不旋转。

● 系统 UI · 守克制

表格 / 状态 / hover / 焦点。--dur-fast 120ms · --dur-base 160ms · --ease-out。只透明度/描线/2px 位移，不缩放。品牌华彩绝不泄进密集界面。

用法 · 把绑定类加到 Coin Seal 的 SVG（styles.css 已含 motion.css）

<!-- 颁章：盖印落定 + 铸缘转光 -->
<div class="gd-strike">
  <svg class="mk" viewBox="0 0 120 120">
    <g class="disc">…铣边奖章…</g>
    <g class="detail">…内方+骑缝…</g>
    <rect class="sweep" …/> <circle class="flash" opacity="0"/>
  </svg>
</div>
/* 系统级：用 token，别用品牌 keyframes */
.card{ transition: transform var(--dur-base) var(--ease-out); }

reduced-motion：@media (prefers-reduced-motion:reduce) 自动关闭全部品牌层动效，画面停在有效静态帧（描金=已描已填、交权=Active 在左、颁章=已成章）。系统级 transition 保留。子元素类名（.disc/.detail/.hl/.hr/.r/.node/.key/.tok…）是绑定契约，须与 SVG 一致。
