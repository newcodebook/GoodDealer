# Atom Standard 下架独立审查

## 交付边界

批量页从同一 Atom 连接的当前库存预览和确认 Standard 下架。local-storage 冻结资产、Listing、连接和扫描代次，签名批准与唯一认领使用原 SQLCipher writer。Native 托管账号凭据，先精确读取，然后最多发送一次官方 `remove-domain`。共享 Cloud 只验证审计、认领和只读对账证据。

`domain-details` 现在只有认证账户内正向挂牌形状。读取失败或挂牌仍在时，客户页显示未核实，已认领项目保持只读。账户内精确缺席、真实账户写入、Windows/macOS 实机和发行分别取证。

## 独立检查

- `standby_native` 静态复核 Native、Host、SQLCipher。核对固定端点、正向挂牌、不可重放认领、撤销、休眠与账号槽栅栏，确认 HTTP 回执、空值及认证错误不会触发解绑或成功。要求补充两个并发选择、提交回滚、重开只读、撤销及重复读回归。
- `device_architecture_review` 独立复核 Cloud、监管用途及客户入口，发现 PostgreSQL 原事实查验在 Atom 分支仍写死 Spaceship。整合时修复为按用途选定的平台，并使用独立数据库验证 Atom 和 SellerHub 两种后继设备只读对账。

隔离 PostgreSQL 18.4 从包含 77 条迁移的 SellerHub 前缀运行新增的两条证据迁移，186 项通过。包含 Atom 认领重放、前任设备事实、后继 observe-only 对账和无写权限拒绝。共享开发与生产环境未部署本切片。
