# SellerHub 固定价上架独立审查

桌面从已托管的 SellerHub 连接保存固定价上架预览。local-storage 冻结连接、资产代次、域名和价格，确认时写入独立的签名批准和每域名一次尝试。Native 预检认证完整库存后才认领。先持久认领再 POST，后续轮次及重开仅执行账户精确 GET。

- Cloud 和签名审查发现迁移目录顺序断言遗漏创建专用审计、事实迁移。补齐后独立复跑目录 11 项通过。协议专项 5 项通过，另外独立验签和拒绝断言 14 项通过。隔离 PostgreSQL 18.4 从 79 条迁移前缀升级至当前目录，187 项通过，包含跨工作区、历史 Lease、配对审计及只读对账控制。
- Local/Native 审查发现新发送技术资格撤回后会阻断已认领项的对账。修订后，当前观察资格允许读取和结算旧项，当前创建资格仍限制新预检、认领和 POST。独立运行 Host 回归通过，撤回后旧 claim 禁发，已认领项可以对账，其他已排队项不推进。
- 桌面回归核对预览后焦点、同一批准只提交一次、回执丢失时读取存档、重开恢复历史及只读状态。Native 解析测试区分等待所有权验证、在售且条款相符及未知。
- 最终根 `pnpm check` 通过。Linux 的 Native Core、local-storage 与 Tauri 全目标严格 Clippy 通过。
- 真实卖家 POST、认证 GET、已授权 DNS TXT 发布及自动验证、Windows/macOS 实机和发行资格分别待取证。
