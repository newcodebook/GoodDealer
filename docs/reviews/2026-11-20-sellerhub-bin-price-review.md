# SellerHub 一口价变更独立审查

独立只读审查核对了批量预览、Host 确认、SQLCipher 提交、ProviderLane、Native 录入和请求、Cloud 证据接收及重开对账。

| 发现 | 修复与复验 |
| --- | --- |
| 对账未比较原事实的重建 canonical 字节和 SQLite 所保存的原始工件。 | 对账重建并严格比较完整 canonical 信封及摘要。测试修改原签名字节对应的 JSON 字段，在原摘要保留时仍拒绝结果。 |
| 已完成账户扫描的有效连接缺少 pending scan，BIN 请求错误地在读取凭据前终止。 | BIN 使用独立的当前权限、连接与项目准入。已归集且无待扫描请求的连接通过精确读取准入。 |
| 批准后撤销连接或改变绑定时，待认领项目从工作选择器消失，界面继续等待。 | 有当前来源权限的未发送项目进入带签名的拒绝结果。测试覆盖撤销后零 Provider 认领、结果记录和执行证据待同步计数。已认领的失效连接保留未知结果。 |

复审确认原事实必须由当前工作区的已接受事实记录匹配，包含原设备、原 Lease、项目及摘要。后继设备可用当前观察权追加对账证据，无法继承原写入批准。已应用迁移及此前 Afternic 签名字节通过升级回归。

本轮使用隔离 PostgreSQL、SQLCipher、原生签名与桌面测试。认证卖家接口、Windows/macOS 实机及发行资格仍待验收。
