# GDBK v2 独立备份审查

两个独立源码审查覆盖了创建授权与锁序、发布顺序和失败处理、IPC 及离线启动回退、认证帧、隔离 SQLCipher、查看与导出边界。未发现阻塞项。跨机器复制后需另行核对目标系统文件所有者、ACL 与原生选择器行为。

SQLCipher 回归使用同一数据库所有者实际创建备份，关闭并移除源数据库及旧安装材料，再由无工作区授权的 Host 使用两份文件恢复业务视图并另存 JSON。异常覆盖错钥、截断、重排、尾随字节、文件链接、重复目标、授权栅栏和仅恢复材料已发布。Linux 原生 GTK 选择和取消使用受控合成文件在实际显示会话运行。

Linux 桌面前端构建和 Linux、Windows GNU 的 local-storage 与 Tauri 严格 Clippy 通过。macOS 交叉构建在 Linux 工具链编译目标 OpenSSL 时中止。Windows/macOS 实机文件选择、双向离线恢复、换机复制权限及发行资格仍需验收。当前切片交付离线查看与导出，授权导入与云恢复分别接续。
