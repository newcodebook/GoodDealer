# ADR-0017：首发版本不包含嵌入式浏览器或浏览器自动化

状态：Accepted v1 product scope; browser automation remains unavailable.

## 决策

首发产品不创建、嵌入或控制远程浏览器页面。它不拥有 Browser Profile、Cookie、密码输入、
多因素认证、DOM 读取/写入、脚本执行、弹窗、下载、上传或网页抓取，也不以浏览器作为 API
能力不足时的回退路径。

需要网页操作的场景可将用户交接到其自己控制的外部 Provider 页面，并呈现脱敏的人工步骤和
非秘密结果要求。用户返回 Desktop 只提供不可信的对账提示；Host 必须另行查询 Provider，
不能把回跳当作转移成功或付款回执。该人工处理不向 GoodDealer 授予页面会话或执行权。

任何未来嵌入式或受控浏览器功能必须通过新的 ADR，逐项定义提供商范围、条款、页面流程、
WebView 平台矩阵、IPC/权限模型、秘密边界、原生观察和独立审查。不能通过恢复旧代码、
测试夹具或通用浏览器接口绕过此决定。

## 理由

浏览器自动化会引入远程不可信内容、登录状态和网页副作用等高风险边界。域名资产的 API
能力和用户控制的外部页面交接可以保留本地秘密隔离；嵌入式浏览器产品化仍需独立决策。

## 当前实现

`automation-host` 报告 `Unavailable`，没有 Desktop 组合。本 ADR 维持该失败关闭状态，而不是
将其视为待接线的占位能力。
