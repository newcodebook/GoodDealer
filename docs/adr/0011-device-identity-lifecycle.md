# ADR-0011：未来设备身份必须使用明确的加密与服务器事实

状态：Accepted design direction; not currently composed.

## 决策

未来设备身份、绑定、轮换和撤销必须由服务器端事实、明确目的的密码学和严格 wire 契约
共同约束。客户端自报身份、安装标识或普通会话不能替代持有证明、范围校验、并发控制或
撤销语义。

## 当前实现

当前仓库没有客户设备身份组合、生产签名 custody、实际凭据存储组合或公共业务服务。该
ADR 因而不声明设备绑定、轮换、撤销或离线行为已经可用。

## 后果

未来实现需先确定服务器端身份域、密码学 custody、轮换权、授权规则、托管数据库资格和
原生观察。每项外部事实都需要独立证据。
