# ADR-0007：未来 Public、Admin 与作业面保持分离

状态：Accepted design direction; no business surface is currently registered.

## 决策

未来客户公开面、内部管理面和后台作业必须拥有独立的身份、授权、路由和业务组合边界。
它们可以共享严格协议和拥有模块的端口，但不得共享无范围的数据库访问、会话或业务权限。

## 当前实现

Cloud 保留边界探针，但公共业务路由和周期作业为空。此处没有已部署的客户或内部管理
服务，也没有后台任务可以执行产品工作。

## 后果

任何未来路由或作业需由具体领域注册，验证不可信输入，执行服务器端租户隔离，并建立
可观察的授权与副作用证据。共享契约不能替代这些组合要求。
