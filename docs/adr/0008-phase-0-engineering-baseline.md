# ADR-0008：Phase 0 使用受锁定的工程基线

状态：Accepted.

## 决策

仓库通过受版本控制的清单、锁文件、工具链配置、结构检查和根检查保持可复现的工程基础。
版本、依赖、生成物和支持范围的变更必须与相关测试和当前文档一同评审。

## 当前限制

工程检查和 CI 配置只证明其实际运行的仓库范围。它们不证明签名应用、原生运行、托管数据
库、提供商行为、持久归档、独立审查、部署、发行或 Gate closure。

## 后果

每个需要外部资格的产品工作包必须额外收集与最终构件或环境绑定的证据；不能把基础工程
检查升级为生产结论。详见[Phase 0 工程基线](../phase0/PHASE0_ENGINEERING_BASELINE.md)。
