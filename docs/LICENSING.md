# GoodDealer License 与商业授权边界

## 适用范围

本文件记录未来商业授权的产品约束。当前仓库没有客户许可证、付款、订阅、设备管理或
合规网页的已组合服务。

## 已接受的目标

未来商业领域应由服务器端事实管理计划、权益、付款状态、退款、访问限制和合规资料。账户
激活时拥有一个个人默认工作区；商业授权与该工作区访问、数据导出/删除和支持流程必须明确
分离。UI 文案、客户端缓存或本地报告不能决定客户权益。

### 目标不变量

- 商业授权的读取和变更从服务器端身份、授权和审计范围推导。
- 平台凭据、恢复材料和其他本地秘密不属于商业领域数据。
- 付款提供商、税务、退款、留存和停服承诺需要明确产品及运营决定。
- 未确定、过期或被撤销的商业状态必须失败关闭，不能由展示层推断为可用。

## 当前组合

Cloud 公共业务路由为空，Desktop 本地业务 Runtime 尚未连接真实账号/订阅/Lease 授权注入，
release 请求未发布且不具资格。因此当前没有完整可用的商业授权、支付或订阅管理路径。

## 交付条件

未来商业服务需要服务器端实现、真实提供商合同、数据保护和保留规则、部署、独立审查及
适用的发行证据。仓库中的类型、静态页面、夹具和检查都不能替代这些条件。
