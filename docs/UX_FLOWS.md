# GoodDealer UX 流程

## 适用范围

本文件定义未来产品界面的状态呈现和交互约束。它不把视觉资产、静态页面或展示组件描述
成已连接的业务流程。

## 目标页面与状态

| 界面模式 | 用户需要看到的内容 | 业务前提 |
| --- | --- | --- |
| 资产列表和详情 | 来源、最后观察时间、版本、状态和不确定性。 | 已验证的共享或本地投影。 |
| 差异预览 | 纳入项、排除项、预期变更、风险和不可逆性。 | 拥有模块生成的有界计划。 |
| 冲突中心 | 用户意图、外部观察和共享投影之间的差异。 | 领域拥有的版本和冲突策略。 |
| 操作历史 | 已确认、失败和未确定结果的区别。 | 可追溯的脱敏结果记录。 |
| Cloudflare 只读连接 | Zone/DNS 观察的可用性、非秘密状态和人工处理要求。 | Cloudflare 最小 Token、具体连接器和 Host 边界。 |
| 数据保护 | 是否实际可用、范围和恢复限制。 | 经批准的 backup/recovery 组合。 |
| 账户与商业页面 | 身份、权益、合规资料和安全状态。 | 真实服务器端账户与商业服务。 |

## 目标交互规则

### 信息呈现

- 显示来源、时间、状态和不确定性；不要把最近一次 UI 渲染当作权威事实。
- 已确认、失败和未确定结果必须有不同的语义和视觉表达。
- 连接器、浏览器或备份不可用时，界面只能呈现失败关闭状态，不模拟成功。首发浏览器功能被
  排除，界面不得把人工步骤渲染为受控网页会话。

### 变更交互

- 批量变更先预览差异和风险，再通过拥有模块请求授权和执行。
- 确认、禁用按钮、加载状态和视觉回调不构成授权或执行完成。
- 失败、部分结果和不确定结果应引导到可追溯的处理，而不是默认重复提交。

### 安全与可访问性

- UI 不得显示、持久化或传递原始秘密。
- `@gooddealer/ui` 负责通用 DOM、键盘、焦点和令牌行为；`@gooddealer/i18n` 负责文案和
  格式化；二者都不拥有业务权限。
- 未来业务流程只能从已验证投影和拥有模块端口获得数据与操作，不直接访问 Host 或网络。

## 当前组合

`@gooddealer/ui`、`@gooddealer/i18n` 和 Desktop 视觉夹具可用于设计验证。Desktop 生产入口
只渲染静态工程基线，未接 Host 或业务渲染，因此上述页面都不是当前可用产品界面。
